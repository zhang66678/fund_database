# 基金分析工作区

在项目根目录的 PowerShell 中启动:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app/streamlit_app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

打开终端显示的本地地址, 通常为 `http://127.0.0.1:8501`. 请使用上述模块启动方式, 不要直接运行 Python 文件. 终端按 `Ctrl+C` 停止服务.

## 临时公网演示

使用 Cloudflare Quick Tunnel 将本机网站映射到临时 HTTPS 地址, 其他电脑无需连接同一 Wi-Fi. 本机网站仍监听 `127.0.0.1`, 不需要开放路由器端口或新增入站防火墙规则.

先按上文启动 Streamlit, 然后在另一个项目终端运行:

```powershell
.\data\tools\cloudflared.exe tunnel --url http://127.0.0.1:8501 --protocol http2 --no-autoupdate
```

将终端中生成的 `https://...trycloudflare.com` 地址发给演示对象. 保持电脑开机联网, 网站和隧道进程持续运行. 隧道终端按 `Ctrl+C` 结束公网访问, 再次启动通常会得到新地址. 此方式没有登录验证, 得到地址的人可以访问 demo, 仅用于临时演示.

隧道工具保存在 Git 忽略的 `data/tools/` 中. 如果由助手后台启动, 进程编号分别记录在 `logs/demo_server.pid` 和 `logs/demo_tunnel.pid`, 日志也在 `logs/`. 停止后台隧道前可核对进程:

```powershell
$demoTunnelId = [int](Get-Content logs/demo_tunnel.pid)
Get-Process -Id $demoTunnelId
# 确认为本次 cloudflared 进程后执行.
Stop-Process -Id $demoTunnelId
```

后台网站可用 `logs/demo_server.pid` 同样核对后停止. 不要在重启电脑后直接复用旧 PID, 它可能已被其他进程使用.

## 页面操作

1. 左侧导航提供"基金分析", "基金对比"和"数据说明". 两个分析页面分别保存编辑条件和已提交结果, 切换导航后可恢复.
2. 搜索区左侧按代码和名称选择本地基金, 右侧保留手动输入. 选择基金同步代码; 手动输入匹配本地基金时同步选项, 否则清空选项, 普通重运行不覆盖手动代码.
3. 图表卡片上方提供近 1 个月, 3 个月, 6 个月, 1 年, 3 年, 全部和自定义范围. 自定义使用两个日期输入框, 上下界来自该基金实际本地净值日期, 且不超过今天.
4. 使用净值多选框选择一条或多条曲线, 默认单位净值. 点击"查询"统一更新概览, 图表, 绩效和资料. 页面不展示原始数据表.

首次打开不预选基金, 基金代码留空并显示空图. 选择或输入基金后默认使用近 1 年范围, 点击查询后展示数据. 快捷范围以所选基金的本地最新净值日为末日, 向前回溯自然月或年, 含两端并限制在本地起止日期内. "全部"取实际最早至最晚净值日, 不使用硬编码年份或今天作为净值末日.

修改基金, 日期或曲线后, 页面明确提示尚未提交, 概览与曲线仍标记上次查询条件. 点击查询后统一更新, 查询失败时清除旧结果, 显示错误并保留空图. 错误反馈在重运行后保持, 下次提交时更新.

基金概览显示成立日期 (`found_date`), 投资类型 (`fund_type`), 业绩比较基准 (`benchmark`), 以及查询区间末条记录的单位净值和累计净值及对应日期, 不重复展示基金名称和代码. 基础资料来自已经入库的 Tushare `fund_basic` 当前档案, 不按净值区间回溯历史资料或历史基准. 页面不请求 Tushare. CSV 模式从同一份基金名单读取这三个字段, 旧名单缺少的字段显示"暂无数据".

概览净值不是实时净值. 始终通过原有服务读取三种净值供概览使用, 绘图只显示勾选的曲线. 末条记录某项缺失时显示"暂无数据", 不使用其他日期的数据补填.

绩效卡片第一行展示年化收益, 年化波动和最大回撤, 第二行展示夏普, 卡玛, 索提诺及年化下行风险. 原有七项指标公式, 单位和精度保持. "指标计算口径"折叠区保留实际区间, 交易日净值记录数, 年化系数, 无风险利率, 目标收益率和排除非交易日披露数量. 不足一年提示直接展示. 缺少日历或有效净值时保留曲线并说明指标不可计算的原因.

经理和资产使用双栏卡片, 窄屏下转为上下排列:

- 基金经理: 按任职日期倒序, 每个任期取最新公告, 默认展开一位. 可查看任职日期, 离任日期, 学历, 公告日期和简历; 多任期在卡片内滚动. 离任日期缺失显示"未提供", 不直接认定在任.
- 资产信息: 展示本地最新资产日期, 公告日期及两种原始金额, 使用千位分隔符. 不随净值区间截取, 不假设单位, 不相加或换算为亿元. 缺失金额显示"未提供".

资料读取失败或尚未入库时保留对应提示, 不影响其他板块. 净值区间无数据时仍可查看该基金已有资料. CSV 对照模式暂不提供经理和资产, 不混用其他数据源. 曲线保持原始量级和 `connectgaps=False`, 不归一化, 不插值或补造披露日期. 页面不请求 Tushare.

## 基金对比

在左侧选择"基金对比", 多选两只或以上本地基金, 选择时间范围后点击"开始对比". 首次进入不预选基金, 始终显示空图与操作提示. 页面沿用单基金页面的浅色主题, 白色卡片, 日期控件和 Plotly 样式.

快捷范围以所选基金的共同净值末日为基准, 默认近 1 年; "全部"取本地共同覆盖范围. 自定义日期限制在该范围内. 提交后服务确定首末共同开市日, 图表明确标注实际比较区间; 请求区间与实际区间不同时补充显示原请求. 没有共同区间或日期非法时显示原因, 不自动跳过缺口寻找其他区间.

图表绘制服务返回的累计收益率, 来源为 `当日复权净值 / 共同起点复权净值 - 1`, 各基金从同一基期的 0% 开始, 纵轴及悬停均使用百分比. 中间缺失保留 NaN 和 `connectgaps=False`, 稀疏序列显示实际观测点. 支持原有 Plotly 缩放, 拖动, 图例开关和统一日期悬停. 原始净值不修改.

下方"绩效对照"以指标为行, 基金为列, 保持原有七项指标的格式和精度. 基金较多时表格内可横向滚动, 指标列固定显示. 某只基金指标不可计算时, 对应列显示"无法计算"并说明原因, 其余基金及已知日期收益仍可展示. 保留不足一年提示和每只基金的计算区间, 样本数, 年化系数, 无风险利率, 目标收益率及排除非交易日披露数量. 日频对比需要完整的 SSE 日历, 特殊基金的适用日历需单独核查.

编辑基金或时间后, 图表及表格继续标注上次已提交结果, 同时提示条件已修改. 再次提交后统一更新; 查询失败时清除旧结果, 错误反馈保持到下次提交. 基金对比与单基金分析使用独立的草稿及结果, 导航往返不会互相覆盖.

## 主题与图表样式

页面使用浅色金融分析主题: 灰蓝背景, 白色卡片, 蓝色主按钮和导航选中状态. 原生主题统一字体, 标题层级, 边框, 圆角和指标字号; CSS 补充卡片间距, 轻微阴影和窄屏换行. 不加载远程字体, 不依赖自动生成的 CSS 类名.

三种曲线颜色固定为单位净值蓝色, 累计净值青绿色, 复权单位净值紫色, 不受选择顺序影响. 图表高度 440px, 使用浅色网格和统一日期悬停, 悬停净值显示四位小数. 日期刻度随缩放调整, 保留 Plotly 缩放和拖动以及缺失值断点. 图表显式使用自己的样式, 避免页面主题覆盖固定配色.

主题配置位于项目根目录的 `.streamlit/config.toml`, 请从项目根目录启动. 修改主题后, 如果页面未刷新为新样式, 在终端按 `Ctrl+C` 停止服务并重新执行启动命令, 然后刷新浏览器.

## 数据与分层

- `bootstrap.py`: 选择文件并组装 Repository 和 Service.
- `streamlit_app.py`: 页面编排, 调用 Service, 查询调度与已提交结果保存.
- `comparison_page.py`: 多基金对比页面编排, 调用既有对比服务并保存独立会话状态.
- `components.py`: 导航, 搜索, 概览及资料展示, 两个页面复用日期筛选和 Plotly 样式.
- `styles.css`: 卡片和导航细节, 辅助文字, 顶部间距及窄屏列换行, 使用组件 key 和语义属性选择器.
- `../.streamlit/config.toml`: Streamlit 原生全局主题, 字体, 圆角和边框配置.
- `FundService`: 规范代码, 整理基金资料, 查询净值与指标; `get_comparison` 负责共同区间, 日期对齐和累计收益序列.
- `DuckDBFundRepository`: 查询净值, 日历, 经理任职记录及资产历史, 处理公告版本.
- `CsvFundRepository`: 读取 CSV, 日期筛选和公告版本处理.

默认查询 `data/fund_database.duckdb`, 基金名称, 净值和日历均来自数据库. 首次使用先执行 `python -m scripts.init_database` 建空库, 再添加基金并更新数据; 也可使用 `--snapshot` 导入已有单基金快照. 只有空库时页面没有可展示的基金数据. 具体命令见 [数据库说明](../database/README.md). 可通过 `DATABASE_PATH` 环境变量指定其他数据库文件, 相对路径以项目根目录为基准.

显式设置 `NAV_CSV` 会优先切换至 CSV 模式, 例如切回原有 10 基金曲线:

```powershell
$env:NAV_CSV = "data/exploration/20260921_095101/longest_lived/history/20260921_102854/nav.csv"
```

以下名称和日历文件配置仅用于 CSV 模式: 相对路径以项目根目录为基准, 也可以使用绝对路径. 名称优先读取净值同目录的 `fund_basic.csv`, 旧目录兼容 `longest_lived/top_10.csv`, 或通过 `FUND_NAMES_CSV` 指定. 下拉框只列出当前数据源有净值的基金, 选项随数据库更新变化.

日历默认读取净值同目录的 `trade_cal.csv`, 或通过 `CALENDAR_CSV` 指定含 `exchange,cal_date,is_open` 的完整 SSE 日历. 未配置日历时仍可看曲线. 目前交易日口径仅在华夏成长上核查, 不应直接用于 QDII 等特殊基金. 已设置的环境变量优先于默认配置, 恢复默认可在终端执行 `Remove-Item Env:NAV_CSV, Env:FUND_NAMES_CSV, Env:CALENDAR_CSV -ErrorAction SilentlyContinue`.

每轮页面运行创建一个服务实例, 从既有 `get_nav` 接口读取净值起止日期供筛选, 当前样本规模暂不使用缓存. 点击查询或开始对比时才计算指标, 单基金查询还读取经理和资产. 编辑条件与已提交结果分开保存在浏览器会话, 修改控件不会自动重新计算指标, 更新数据库后需重新提交查询. 单基金查询接口和指标公式保持原有口径, 对比计算由服务层统一提供.

## 验证

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_streamlit_app.py tests/test_fund_service.py tests/test_fund_metrics.py -q
```

页面测试使用临时 DuckDB, 覆盖单基金原有查询行为, 多基金对比, 自定义日期, 两个页面的独立状态, 导航往返, 未提交条件提示, 数据缺口, 无共同区间和读取失败. 共 7 项页面测试, 加上服务及指标测试共 23 项通过, 对比页面仅在已有文件中新增 2 项测试.

已用隔离 Chrome 检查两只及四只基金的实际对比页面, 桌面 1440px 和窄屏 900px 下未发现整页横向溢出. 指标表在窄屏内横向滚动, 图例位于绘图区上方. 本地截图保存在 Git 忽略的 `logs/ui_comparison_preview/`.

人工查看时可先查询一只本地基金, 检查顶部标题, 卡片边界, 图表配色和指标对齐, 再缩窄浏览器查看经理与资产是否转为上下排列. 可分别勾选三种净值, 确认颜色不变且悬停日期与净值清晰; 数据说明页应使用同一套卡片风格.

再进入基金对比, 选择华夏成长和华安创新, 用近 1 年范围提交, 检查共同起点为 0% 且七项指标正常显示. 加入其他基金后先观察未提交提示, 再提交更新. 切换回单基金分析, 两个页面的条件和结果应分别保持.
