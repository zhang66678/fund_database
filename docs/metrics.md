# 指标与对比口径

本文说明单基金绩效、累计收益、回撤和多基金对比的计算规则。实现位于 `services/fund_metrics.py` 和 `services/fund_service.py`。

## 数据基础

- 指标统一使用复权单位净值 `adj_nav`，不受页面勾选的曲线类型影响。
- 日期按 SSE 交易日历的 `is_open=1` 筛选。
- 缺失比例为缺少有效复权净值的开市日数 / 区间应有开市日数, 不超过 1% 时允许计算; 超过 1% 时整组指标不可计算.
- 缺失净值不填充或插值. 日收益仅使用相邻开市日均有有效净值的样本, 不将跨缺口的涨幅视为单日收益.
- 非开市日披露保留在原始数据中，但不进入指标序列。
- 分红已经包含在供应商的复权净值口径中，不再额外加回。

## 七项指标

令：

- $P_t$：第 $t$ 个开市日的复权净值。
- $r_t = P_t / P_{t-1} - 1$：相邻开市日均有有效净值时的日收益率.
- $A = 252$：年化交易日系数。
- $D$：区间首末日期之间的自然日数。
- $R_f$：年化无风险利率，默认 0。
- $MAR$：年化目标收益率，默认 0。
- $f = (1+R_f)^{1/A}-1$，$m = (1+MAR)^{1/A}-1$。

| 指标 | 公式 |
| --- | --- |
| 年化收益 | $(P_{last}/P_{first})^{365.25/D}-1$ |
| 年化波动 | $\mathrm{std}(r_t, ddof=1)\times\sqrt{A}$ |
| 最大回撤 | $\max(1-P_t/\mathrm{cummax}(P)_t)$，以正值展示 |
| 夏普比率 | $\mathrm{mean}(r_t-f)\times A / \text{年化波动}$ |
| 年化下行风险 | $\sqrt{\mathrm{mean}(\min(r_t-m,0)^2)\times A}$ |
| 索提诺比率 | $\mathrm{mean}(r_t-m)\times A / \text{年化下行风险}$ |
| 卡玛比率 | 年化收益 / 最大回撤 |

说明：

- 夏普和索提诺的分子使用日收益算术均值年化，不直接用复合年化收益替代。
- 下行风险分母使用全部收益观测数量，不是只统计下跌日。
- 卡玛按用户所选区间计算，不强制 36 个月。
- 年化收益使用自然日跨度，波动和比率使用 252 个交易日。
- 年化收益使用首末净值, 最大回撤使用已观测有效净值; 波动, 夏普和下行风险等使用有效相邻日收益样本, 下行风险分母为这批收益的总数.

## 边界规则

- 有效净值少于 2 个, 或存在非正, 非有限值时不计算指标; 空值计入缺失比例.
- 标准差、下行风险或最大回撤为 0 时，对应比率返回“无法计算”，不返回无穷大。
- 区间不足一年时保留结果, 标注统计区间不足一年.
- 日历不完整, 首末开市日净值缺失, 或缺失比例超过 1% 时, 整组指标不可计算.
- 返回结果同时包含实际起止日, 应有及有效净值数, 缺失数量和比例, 有效收益数, 年化参数和排除的非交易日数量.

## 累计收益与回撤序列

`FundService.get_performance_series()` 返回：

- 累计收益：$P_t / P_{first} - 1$，区间首个开市日为 0%。
- 回撤：$P_t / \mathrm{cummax}(P)_t - 1$，数值不大于 0。

回撤峰值只从所选区间开始累计，不引用区间之前的历史峰值。最大回撤卡片展示正值，完整数据下等于回撤曲线最低点的绝对值。

缺失开市日保留为 NaN，不填充、不插值；图表使用 `connectgaps=False` 保留断点。

## 宽基累计收益对比

单基金图表可选择沪深300, 中证500, 中证1000, 上证50和创业板指. 指数使用 Tushare `index_daily.close` 计算 `close_t / close_base - 1`, 为价格指数累计涨跌幅; 基金仍使用复权净值, 包含供应商复权口径下的分红.

指数严格复用基金收益曲线的首个开市日作为基期, 两者从同日的 0% 开始. 指数按基金曲线的开市日序列对齐, 内部缺失或无效收盘价保留断点, 不填充. 基期缺失时该指数不绘制, 提示缩短区间或更新数据; 不移动基金基期. 末段数据不足时展示已有部分并标注指数实际截止日.

指数曲线与基金累计收益共用右侧百分比轴, 不改变基金绩效指标, 回撤或同类排名. iFinD 基金在线模式下, 指数仍明确使用本地 Tushare 数据; CSV 对照模式暂不提供指数行情.

## 多基金对比

`FundService.get_comparison()`：

1. 规范化代码并去重，至少两只基金。
2. 按请求区间取每只基金净值。
3. 取各基金覆盖范围的交集，并定位首末共同开市日。
4. 用共同开市日对齐，计算从 0% 开始的累计收益。
5. 逐只复用 `get_metrics()`，区间统一为实际共同区间。

结果包含：

- `requested_start_date` / `requested_end_date`：用户请求区间。
- `start_date` / `end_date`：实际比较区间。
- `cumulative_returns`：日期 + 各基金累计收益。
- `metrics`：每只基金的完整指标结果。
- `errors`：不可计算指标的原因。

某只基金指标不可计算时，不影响其他基金和已知日期的累计收益曲线。

### 指标着色

对比表格按行着色：

- 年化收益、夏普、卡玛、索提诺：越高越优，最优红色。
- 年化波动、年化下行风险、最大回撤：越低越优，最优红色。
- 最差值绿色；中间值、全部相同或无法计算时不着色。

颜色只表示本次对比的相对排序，不修改数值或公式。

## 固定周期涨幅与细分类比较

数据层入口为 `FundService.get_peer_returns()`. 基金分析页在绩效和分红下方整行展示, 点击查询时计算, 切换标签页复用结果, 不随图表区间截取.

- 阶段: 近一周, 近一月, 近三月, 近半年, 今年来, 近一年, 近三年.
- 季度: 基金最新净值日所在季度及之前七个季度, 当前季度只计算截至最新净值日的涨幅.
- 年度: 基金最新净值日所在年度及之前七年, 当前年度标记为未结束.
- 截止日期不晚于今天; 周期独立于图表的查询区间. 每月和每年按自然日回溯, 今年来和完整季度/年度以周期开始前一天为基期.
- 非披露日取不晚于周期边界的最近净值日, 距离边界超过 14 个自然日则该周期无法计算; 不缩短历史不足基金的区间.
- 每周期涨幅为 `adj_nav_end / adj_nav_start - 1`, 不年化, 不要求区间内部净值连续, 也不依赖 SSE 日历完整性. 七项日频绩效指标另按 SSE 日历检查缺失比例, 上限为 1%.
- 同类采用每只基金最近采集的 iFinD 投资类型 `一级 / 二级` 完整路径, 保留三级原值但不混用层级; 各周期要求同类基金具有与本基金完全一致的基期和末日净值, 每日取最新公告版本, 最新版本缺值时不回退旧版本.
- 仅使用本地有基础资料和净值的基金. 不同份额代码分别计入, 不按当前存续状态过滤历史数据. 两个边界必须都有正且有限的复权净值.
- 同类平均为有效样本的等权平均, 包含本基金; 至少两只有效样本且本基金在样本中才提供比较结果.
- 排名按涨幅降序, 保留 12 位小数判断并列, 并列采用最小名次. 排名同时返回有效样本数, 不把缺数据基金计入分母.
- 四分位为 `ceil(排名 / 样本数 * 4)`, 1 至 4 分别为优秀, 良好, 一般, 不佳. 少于四只有效样本时不提供四分位.
- 输出包含分类来源, 分类获取日期, 实际计算起止日, 样本数及不可计算原因. 无分类时仍可计算本基金涨幅, 同类数据保持缺失.
- 此结果采用 iFinD 分类和本地 Tushare 净值计算, 不等同于数据供应商的官方排名或同类指数收益. 当前分类应用于历史周期, 不作为历史时点可得的研究数据.
- iFinD 在线模式已提供单基金分类查询, 同类基金的批量净值比较仍未接入; CSV 模式暂不提供细分类同类比较. 不混用 Tushare 净值作为在线模式排名.

## 已知限制

- 当前统一使用 SSE 日历；QDII、货币基金等特殊产品的适用日历需单独核查。
- 部分基金成立初期披露稀疏，导致全历史指标不可计算；可以缩短区间后重试。
- CSV 对照模式没有完整日历或分红数据时，对应指标或板块不可用。
- 指标结果依赖本地已下载数据；增量窗口外的修订需用 `--full-history` 复查。
