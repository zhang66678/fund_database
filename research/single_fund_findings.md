## 4. 七项指标计算约定 (已确认并实现)

令 P 为筛选后正且有限的 adj_nav 序列, r_t = P_t / P_(t-1) - 1, n 为有效日收益数量, A = 252. 端点日历天数为 D. 不默认纳入开始日期之前的净值, 因而区间收益从实际首条净值开始.

无风险年利率 Rf 和最低目标年收益 MAR 先使用可配置常数 0, 这只是演示假设, 不是 Tushare 实际利率. 日化分别为 f = (1+Rf)^(1/A)-1, m = (1+MAR)^(1/A)-1. 两项参数需大于 -1. 后续若引入利率接口, 先确定币种, 期限和对齐方式, 不把任意利率自动当作无风险收益.

| 指标 | 首版公式 |
| --- | --- |
| 年化收益 | (P_last/P_first)^(365.25/D)-1 |
| 年化波动 | std(r, ddof=1) * sqrt(A) |
| 最大回撤 | max(1 - P_t / cummax(P)_t), 展示为正的损失幅度 |
| 夏普比率 | mean(r-f) / std(r-f, ddof=1) * sqrt(A) |
| 年化下行风险 | sqrt(mean(min(r-m, 0)^2)) * sqrt(A) |
| 索提诺比率 | mean(r-m) * A / 年化下行风险 |
| 卡玛比率 | 复合年化收益 / 最大回撤 |

夏普和索提诺的分子使用日收益的算术均值年化, 不直接用页面上的复合年化收益代替. 下行风险分母用所有收益观测的数量, 不是仅负收益天数, 也不是负收益样本标准差. 卡玛按用户区间计算, 不强制固定 36 个月, 页面需说明.

夏普口径参考 [Sharpe 1994 原文](https://web.stanford.edu/~wfsharpe/art/sr/sr.htm). 上表为本项目明确选用的实现约定, 不保证与第三方网站的不同频率, 不同利率和不同区间算法一致. sqrt(A) 年化是常规近似, 不进行收益自相关修正.

边界规则:

- 数据为空, 日期冲突, 非法或非正复权净值时不能输出误导性指标. 不以前向填充或单位净值代替缺失复权净值.
- 收益样本少于 2 个时, 不提供依赖样本标准差的指标. 无有效时间跨度时不计算复合年化收益.
- 最大回撤, 标准差或下行风险为 0 时, 相应比率显示无法计算, 不返回无穷大.
- 区间不足一年时标记短区间年化. 实际首尾日期和样本数量同时展示.
- 日频净值存在开市日缺口时, 首版阻止整套日频指标输出并说明原因, 不把跨缺口收益当单日收益. 稀疏历史净值仍可展示.
- 分红已包含在供应商复权净值口径中, 不再额外加分红. 复权方法与真实投资者到账及再投资时间的差异仍需后续用分红样例核对.

## 6. 指标实现与试算

已按确认口径实现 `services/fund_metrics.py` 中的 `calculate_metrics`. 该函数只接收单只基金净值和完整 SSE 日历的 DataFrame, 不读取文件, 不访问接口. 输入净值需先完成日期区间筛选及公告版本选择. 年化参数通过关键字参数集中传入, 默认 252, 0%, 0%.

在项目根目录启动 Python 后可执行:

```python
from pathlib import Path
import pandas as pd
from services.fund_metrics import calculate_metrics

folder = Path("data/single_fund_audit/20261012_093903")
nav = pd.read_csv(folder / "fund_nav.csv", dtype={"nav_date": str})
calendar = pd.read_csv(folder / "trade_cal.csv", dtype={"cal_date": str})
nav = nav[nav.nav_date.between("20200101", "20251231")]
result = calculate_metrics(nav, calendar)
result["metrics"]
```

返回值中的收益和风险为小数, 页面展示百分比时乘 100. 比率不乘 100. 返回值同时记录实际区间, 样本数, 年化参数及短区间标记. 无定义的比率返回 None.
